# Rhombic-stirling-model
Rhombic stirling engine model replicating the motion created by the rhombic drive.
Note that this is not tested/does not run, because the plastic would melt from heat sources such as fire!

# Print settings
-> Print settings should be default
- The bearings should be printed so that their flat face is down; they are designed to be print in place
- Cylinders and pistons should be printed with the circular face facing the printer bed for the best quality
- The stand holding the gears should be printed so that the stand is positioned horizontally to maximize strength
- Everything else can be printed according to preference! :D
