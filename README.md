# Rhombic-stirling-model
Rhombic stirling engine model replicating the motion created by the rhombic drive.
Note that this is not tested/does not run, because the plastic would melt from heat sources such as fire!

# Print settings
-> Print settings should be default
- The bearings should be printed so that their flat face is down; they are designed to be print in place
- Cylinders and pistons should be printed with the circular face facing the printer bed for the best quality
- The stand holding the gears should be printed so that the stand is positioned horizontally to maximize strength
- Everything else can be printed according to preference! :D
# Bill of materials
- Glass watch screws and bolts with screw driver (9 screws, 4 bolts)-> $7.99 -> https://a.co/d/00xMulaC
- 2mm screws (2 screws with 4 mm height, and at least 4 screws with 12-16 mm height) -> $6.99 -> https://a.co/d/043UEMKD
- Super glue (1) -> $9.99 -> https://a.co/d/04ECuO9W

# Assembly
<i>Print out all the parts!</i>

Here is the CAD for reference: https://cad.onshape.com/documents/a88638ba70845716c60d09ad/w/95721509719e81cc85900464/e/23355bab8f0dd3e4b7a81d09?renderMode=0&uiState=6ae153af595165037360c70a

<u>Notes</u>

**Holes indicate holes for screws that you can use to connect the parts.**

**During assembly, screws for the gear holder use the 2mm screws, while screws for the linkage require the glass watch screws!**

**Glue the cylinder to the stand using your super glue**
